# Drawings

Drop a PNG in here and it appears on the site automatically — no code change.
Transparent background, please.

| Filename          | Where it appears                                          | Status |
| ----------------- | --------------------------------------------------------- | ------ |
| `submarine.png`   | Landing hero, registration page, 404                       | done   |
| `seaweed.png`     | Landing hero, bottom corners                               | done   |
| `anglerfish.png`  | The dark "deep" band on the landing page, and the 404 page | wanted |
| `treasure.png`    | The prizes card in the landing page round section          | wanted |

A slot with no file simply renders nothing — no gap, no broken image icon —
so it is safe to add these one at a time.

Guidance: tall-ish for `anglerfish` (it sits in a dark band, so light linework
reads best), roughly square for `treasure`. 800–1400px on the long edge is
plenty. Run `npm run photos` only for team portraits; these are left alone.
